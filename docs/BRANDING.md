# VistaPlay Branding

## Official app icon

The official VistaPlay app icon is the white rounded-square mark with a soft shadow and an orange-yellow `VP` / play monogram, adopted on 2026-08-31.

Production assets:
- `public/icon-192.webp`
- `public/icon-512.webp`
- `public/maskable-512.webp`

This artwork is the canonical VistaPlay app identity. Do not replace it with the previous flat SVG/PNG icon set without an explicit branding decision.
